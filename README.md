# Veebilehe-Projekt

Selle projekti eesmärk on ehitada veebileht, mis hõlmab toidu retsepte koos piltide, koostisosade loetelu ja valmistamis juhendit.
Veebilehe ülesehituseks on plaanis :
  1. Avaleht, kus on veebilehe kohta üldine informatsioon nt kuidas veebilehte kasutada ja kust on retseptid leitud.
  2. Vaheleht, kus kuvatakse kõik andmebaasis olemasolevad retseptid. Lehel on ka olemas otsingu riba koos filtritega, et retseptide otsimist teha kergemaks.
  3. Vaheleht, kus on kuvatud kasutaja poolt valitud retepti info - retsepti nimi, pilt, koostisosad, valmistamis juhend ja millistele dieetidele retsept vastab.
